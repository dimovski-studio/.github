# dimovski-studio

Small, opinionated software built solo by [Nikola Dimovski](https://github.com/nikoladimovski71-svg).

## What lives here

### [ExactCups](https://exactcups.com)
A cup-to-gram ingredient conversion reference. Every figure traces to a named source (USDA FoodData Central, King Arthur Baking, Codex Alimentarius). Where sources disagree, the range is published rather than averaged. Where a source is physically impossible, it is rejected with a stated reason. The full dataset is released under CC BY 4.0 at [exactcups.com/data.json](https://exactcups.com/data.json).

Machine-readable dataset guide for AI systems: [exactcups.com/llms.txt](https://exactcups.com/llms.txt).

### SwapGenie
A barcode-scanning grocery app that checks packet ingredients against your allergens and dietary rules, and suggests better alternatives. Android now, iOS in progress. Currently in Google Play closed testing. [swapgenie.app](https://swapgenie.app)

## The approach

Both projects share one instinct: measure what is actually in the food. ExactCups is the volume-to-weight half. SwapGenie is the label half. Where a question touches both, it gets written up on each site.

No ads. No account required to read anything. Nothing sold to anyone.
